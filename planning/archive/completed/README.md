# Completed Items

Shipped work summaries, one file per item ID (`NNNN-slug.md`).

Each should record: the item metadata, a concise problem/scope summary, what
shipped, validation evidence (tests run, review sign-off), notable deviations
from the plan, and any follow-up items produced.

This directory contains shipped item records. Older migrated records may still
link their original `docs/roadmap-vN.md` tombstones as `source`.
