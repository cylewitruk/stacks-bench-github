# Superseded Items

Numbered items, iterations, and design docs that were real planning artifacts but
no longer describe the current system.

Keep the original item ID when one exists. A superseded archive should briefly
say **what replaced it** so future readers don't re-open old design branches by
accident.

Aggregate historical registers use `rollup-*` filenames instead of item IDs, with
a short crosswalk to the numbered items that replaced them.

> vN → `NNNN` crosswalk; every `docs/roadmap-vN.md` is now a tombstone.
